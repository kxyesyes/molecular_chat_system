# 分子聊天系统 (Molecular Chat System)

## 项目概述

分子聊天系统是一个面向药物设计与药物化学场景的智能 Web 平台，目标是把分子研发中的关键环节整合到同一套工作流中，实现从自然语言交互、知识检索、分子生成，到分子设计、分子对接、反向寻靶、活性预测和 ADMET 评估的端到端辅助分析。

项目以 Web 网站的形式提供服务，面向药物设计研究人员和药物化学专家。系统支持自然语言输入，能够输出文本结果、表格信息、分子结构相关内容以及可下载文件，适用于方案探索、候选分子筛选和研发流程自动化。

本项目当前处于毕业设计开发阶段。分子生成部分采用了自定义微调的 Llama3-8B 模型，使模型具备生成 SMILES 的能力；同时引入 Agent 思路，将多个工具和分析模块串联起来，提升药物设计任务的自动化程度与交互体验。

## 核心能力

- 智能对话问答，支持面向药物化学问题的自然语言交互
- RAG 检索增强生成，用于结合分子知识库进行辅助回答
- 分子生成与分子设计，支持基于大语言模型的 SMILES 输出
- 分子对接，用于评估候选分子与靶点的结合可能性
- 反向寻靶，用于探索潜在靶点与作用机制
- 活性预测，用于辅助筛选更有潜力的候选分子
- ADMET 预测，用于评估吸收、分布、代谢、排泄等性质

## 适用场景

- 药物分子初步设计与候选生成
- 分子性质分析与快速筛选
- 靶点相关的辅助检索与证据整理
- 药物研发流程中的多步骤自动化辅助

## 技术特点

- 采用 Web 架构，便于本地调试和后续服务器部署
- 使用 Ollama 作为本地大模型推理基础设施
- 结合 FAISS 与分子数据构建检索能力
- 模块化设计，便于扩展新的化学工具与智能体能力
- 面向药物设计任务进行了场景化整合，而非单一功能演示

## 快速开始

### 环境要求

- Python 3.7+
- Ollama 本地服务
- 建议具备 8GB 以上内存

### 安装依赖

```bash
pip install -r requirements.txt
```

### 启动项目

```bash
python main.py
```

启动后访问 Web 首页即可开始使用。默认情况下，服务会运行在本地开发环境中，后续也可以迁移到 Linux 服务器部署。
