# 首页中轴工作台重排设计

日期：2026-04-21  
范围：首页首屏主体布局重排  
涉及文件：
- `src/web/templates/index.html`
- `src/web/static/js/script.js`

## 1. 目标

在不修改顶栏的前提下，重新整理首页首屏排版，使其更符合“专业、干净、留白多”的科研工作台气质。

本轮改造聚焦于结构重排，而不是大幅更换视觉语言。首页需要从当前“欢迎页 + 多个浮层控件并置”的状态，调整为“中轴聚焦、输入优先、主题切换可见但克制”的工具首页。

## 2. 约束

- 顶栏保留，暂不修改。
- 左侧功能导航默认收起。
- 三套首页主题保留，并作为首页可见亮点。
- 主题不控制最底层背景，只作用于强调层。
- 第一轮只做首页主体重排，不进行第二轮细节精修。

## 3. 现状问题

当前首页存在以下问题：

1. 视觉中心不明确。品牌区、主题切换、快捷卡片、输入区都在争抢注意力。
2. 页面像“欢迎页”而不是“工作台”。用户进入后不够明确第一步该做什么。
3. 快捷入口体量偏重，抢走了输入框作为主操作入口的角色。
4. 主题切换虽然可见，但形态更像横向工具带，而不是一个高质量亮点控件。
5. 左侧导航展开时对首页主体造成压迫，不利于大屏下形成安静的中轴布局。

## 4. 设计方向

本次采用“中轴工作台”方案：

- 顶栏下方的首页内容全部围绕中轴展开。
- 输入区成为首屏唯一核心焦点。
- 主题切换保留在上方，作为可见亮点，但不能喧宾夺主。
- 快捷入口降级为次级操作层，置于输入区之后。
- 左侧导航默认收起，只保留最小存在感。

整体气质目标：

- 专业
- 克制
- 浅色
- 留白充足
- 适合 2560×1600 大屏使用

## 5. 首屏结构

首页首屏由上到下拆分为五层：

### 5.1 主题切换层

位置：顶栏下方，首屏上部居中。  
形式：短胶囊容器，包含“首页主题”标签与三个主题按钮。  
要求：

- 宽度收紧，不铺成横带。
- 三个主题按钮尺寸统一。
- 控件整体精致、轻量，像一个实验台上的控制器。
- 保持可见亮点，但视觉权重低于输入框和标题区。

### 5.2 标题区

位置：主题切换层下方。  
内容：

- 品牌 logo
- `MedChat`
- 更短、更克制的副标题

要求：

- 比当前版本更紧凑。
- 减少“欢迎页海报感”。
- 与输入区形成紧密连续关系。

### 5.3 输入区

位置：首屏中轴核心。  
要求：

- 作为首页第一视觉焦点。
- 宽度足够，但不能过于松散。
- 发送按钮、语音按钮、附件按钮整合为一个统一输入操作组。
- 输入框质感轻盈，阴影和高光克制。

### 5.4 工具开关层

位置：输入区下方，紧贴输入框。  
内容：

- `RAG 检索`
- `智能工具`
- `高级选项`

要求：

- 三者位于同一操作层。
- 高级选项不再孤立漂浮。
- 文本、图标、间距统一。
- 整体像输入框的附属工具栏。

### 5.5 快捷入口层

位置：工具开关层下方。  
内容：

- 3 个精选能力入口

要求：

- 降低卡片体量。
- 保持横向排列。
- 以轻量卡或胶囊卡为主，不再做厚重大白砖。
- hover 仅保留轻微抬升与边框高亮。

## 6. 布局比例

针对 2560×1600 屏幕，首页主体采用中轴布局，控制内容最大宽度，避免内容过散。

建议值：

- 主体最大宽度：`1280px ~ 1440px`
- 主题切换与标题区之间：`40px` 左右
- 标题区与输入区之间：`36px` 左右
- 输入区与开关层之间：`18px` 左右
- 开关层与快捷入口之间：`42px ~ 56px`

视觉权重顺序：

1. 输入区
2. 标题区
3. 主题切换
4. 快捷入口
5. 辅助按钮

## 7. 左侧导航策略

左侧导航默认收起，目标是减少首页主体受干扰的程度。

要求：

- 默认状态下仅显示窄边控制条或展开按钮。
- 首页首屏以中轴内容为主，不让左侧导航打断节奏。
- 展开交互保留原能力，但不是首页默认状态。

## 8. 主题系统策略

三套主题保留：

- 粉雾
- 琥珀
- 薄荷

主题应用范围限制为强调层：

- 输入框 focus 状态
- 按钮强调色
- 卡片 hover 边框
- 图标高亮
- 局部柔和光晕

主题不应用到页面最底层背景，避免整页色彩情绪过重，影响“专业、克制”的整体气质。

## 9. 实现范围

本轮仅处理以下内容：

1. 首页主体 DOM 排列顺序调整
2. 左侧导航默认收起
3. 主题切换位置与样式重构
4. 标题区重排
5. 输入区重排
6. 工具开关层与高级选项归并
7. 快捷入口降级与轻量化

本轮不处理：

1. 顶栏改版
2. 首页第二屏或更深层内容重构
3. 左侧导航内容本身的重新设计
4. 第二轮细节美化

## 10. 风险与兼容性

需要注意的风险：

1. `chat-mode` 依赖当前首页 DOM 结构，重排时必须保证聊天模式切换不被破坏。
2. 主题切换逻辑已在 `script.js` 中实现，重排时应复用既有逻辑，不重复造轮子。
3. 左侧栏默认收起后，要确认展开/收起按钮仍然可访问。
4. 首页当前样式存在多处重复声明，重排时需要采用“明确覆盖”方式，避免旧样式抢权。

## 11. 验收标准

完成后应满足：

1. 顶栏保持现状，无明显视觉回归。
2. 左侧导航进入首页时默认收起。
3. 首页主体视觉中心清晰，输入框成为首屏第一焦点。
4. 主题切换保持可见且更精致，不再像横向功能带。
5. 快捷入口明显降级，不再压过输入区。
6. 在 2560×1600 屏幕下，页面不显散乱，留白自然。
7. 聊天模式切换、主题切换、快捷入口点击保持正常。
