# 首页运行中改目标

首页的“按目标分析”接受自由文本。用户开启科学工具后，模型可以为本轮目标选择理化性质、类药规则或已指定 UniProt 条目的结构检索。模型根据真实结果重新决定下一步。用户给出的完整结构和标识符约束可用输入，科学工具负责计算和核验。

每个目标属于创建它的 WebSocket 和会话，初始修订号为 1。更新必须同时匹配连接、轮次、追踪号和当前修订号。接收更新后，服务端停止派发旧计划，收回迟到的模型提案；已启动的只读工作允许收尾。新计划可以引用相同工具、版本、完整输入及参数产生的已核验结果。最终答复只交付当前修订所用的证据。

耗时和调用次数由整个目标共用。停止或断开连接时，执行器负责回收在途工作。已有带确认的任务继续通过原入口提交。
