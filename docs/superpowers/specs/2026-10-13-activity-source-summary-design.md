# 活性预测来源摘要设计

## 目标

将活性预测结果中的“查看本次预测来源”从完整 `provenance` JSON 改为面向用户的最小摘要，避免哈希、模型卡和内部绑定字段占满结果表。

## 设计

- 保留后端返回的完整 `provenance`，不改变 API 契约或科学追溯数据。
- 前端折叠区域只显示两项：可读的模型版本（例如 `r2`）和验证说明。
- 模型版本从 bundle ID 中提取；无法识别时显示“已绑定模型”，不展示原始长 ID。
- 验证说明明确区分“模型推理结果，非实验验证”和已明确验证的情况。
- 失败或缺少来源时显示“来源不可用”，继续保留现有错误/警告文本。

## 验证

更新原生 JavaScript DOM 测试，确认摘要只包含允许的信息、不包含 bundle ID、哈希和嵌套 JSON，并继续使用安全的文本节点渲染。
