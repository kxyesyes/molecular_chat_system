# PDE / BuChE 家族模型与分类后回归设计

状态：核心交互规则已由用户确认；本书面设计待审阅。它补充活性数据就绪层任务 7，
不表示真实数据已完成准备、模型已训练或当前服务已切换。

## 1. 已确认需求

- PDE 及其亚型（包括 PDE5A）使用同一个 PDE 模型组。
- BuChE 及其名称/物种变体使用同一个 BuChE 模型组。
- 两个家族的数据与权重相互隔离，不互相回退。
- 用户已确认输入 `pIC50` 的定义为 `-log10(IC50 [mol/L])`，不再次取对数。
- 分类训练标签：`pIC50 >= 5` 为 `1 / 有活性`，`pIC50 < 5` 为 `0 / 无活性`。
- 先分类，再对所有有效分子做 pIC50 回归；包括分类为“无活性”的分子。
- 前端不重复附加数据范围提示；模型卡和机器可读溯源保留混合亚型/物种、未知实验来源等真实信息。
- 输出均为模型预测，不能称作已由实验确认的活性或亚型特异性验证。

## 2. 当前代码基础

- `src/activity/dataset_contract.py` 已有 pIC50 identity / binary_threshold 转换、
  重复记录聚合与完整证据、确定性三路 scaffold 拆分。
- `src/activity/model_card.py` 已有 prepared 数据验证、模型卡构造和原子发布。
- `src/activity/prepared_training.py` 已有真实 RGNN 训练、validation 选模/早停、
  最佳权重恢复后单次 test 评估及代码/数据 provenance。
- `src/activity/model_registry.py` 已有按 endpoint 选择模型与产物校验，
  尚未实现分类和回归模型的成组激活。
- `src/activity/predictor.py`、`src/agent/tools/activity_predictor_tool.py` 与
  `src/web/routes/api_routes.py` 尚未完成原计划任务 7 的端点隔离迁移。

复用这些组件，不替换 RG-MPNN、不引入另一套训练平台，也不迁移前端技术栈。

## 3. 方案比较与选择

1. **分类器 + 全范围回归器，顺序执行（采用）**：每家族两个独立 RGNN 权重，
   共享分子拆分，所有有效输入均可得到两种预测。符合用户确认，也便于独立定位失败。
2. 分类器筛选阳性后才回归：会隐藏阴性分子的数值，用户已选择不采用。
3. 单一多任务网络，或将分类概率作为回归特征：需要修改网络/损失或引入严格的
   out-of-fold 特征，扩大范围；本轮不采用，也不声称顺序调用本身提升回归精度。

## 4. 数据准备与标签

### 4.1 原始数据和来源

用户提供的 CSV 只有 `Smiles`、`pIC50` 两列。原文件只读，不改名、不覆盖，
不提交 Git。训练资产与原始来源位置保留在本机忽略目录，文档只使用逻辑标识。

受控 family ID 使用 `pde-family`、`buche-family`，不冒用某个单一 UniProt 编号。
授权记录为用户允许本项目训练，不扩展为允许公开再分发数据。
来源和物种记录为 user-provided / mixed / unspecified-detail，不编造文献、assay 或物种。
原文件未提供测量关系符；记录“输入为提供者给出的点标签，删失情况未知”，
不得在模型卡中写成已逐条核验实验关系符。

### 4.2 结构与重复数据

沿用现有母体标准化契约；无法唯一确定母体的多片段记录隔离，不擅自选取片段。
无效结构、非有限标签不得进入训练。两份数据不混合训练。

建议延续已有中位数策略：按同一家族内 canonical SMILES 聚合为一个**混合记录中位数标签**，
保留每条原始值、记录数、离散程度及跨阈值情况。不把不同来源记录称作同一实验的重复测量，
也不把聚合标签描述成单一亚型的精确实验值。
这项聚合策略须随本设计审阅，不在审阅前对真实数据执行。

分类标签从聚合后的连续 pIC50 以 `>= 5` 派生，而不是先逐行二值化再取中位数。
回归器使用所有合格聚合分子，包括 pIC50 小于 5 的分子。
归档冲突组数、标签范围和跨 5 的组数，但不因结果不好而秘密丢弃冲突组。

### 4.3 同一拆分用于两个阶段

先建立一次按 scaffold 分组的 70/15/15 train/validation/test 分配，默认 seed=42。
分类和回归的数据集共享精确的 canonical SMILES 与 scaffold 分配，而不只记录同一个 seed。
两份 prepared manifest 的内容哈希允许不同，因为任务及标签不同；成组描述文件必须记录
共同原始来源摘要、分子分配摘要与两个 prepared manifest 的摘要。

分类三路均须含两类；回归评估集须能计算规定指标。条件不满足则停止，不降低质量门，
也不反复查看 test 表现来挑拆分或调整分类阈值。

## 5. 模型组与路由

每家族模型组保存：

- `family_id`、`bundle_id`、版本、标签阈值 5 与边界 `greater_or_equal`；
- classification 与 regression 的 model_id、权重摘要、模型卡摘要、任务/终点/单位；
- 两阶段各自的 prepared 摘要和共同 source / split assignment 摘要；
- 训练配置、验证集/测试集指标、数据授权与来源范围。

分类模型用现有 `binary_threshold` 任务契约；回归模型用 `pIC50` identity 契约。
新增成组激活逻辑应使用现有注册表事务/锁：只有两阶段都通过校验才切换活动模型组。
不得用两个互不关联的 active endpoint 更新制造半旧半新的模型组。

家族解析使用受控别名与边界匹配，而不是全文任意子串：

- PDE、明确的 PDE 亚型表达（如 PDE5A、PDE4D）归一到 `pde-family`。
- BuChE、BChE、丁酰胆碱酯酶归一到 `buche-family`，大小写不敏感。
- 不将 AChE 误归到 BuChE；未识别靶点不得默认用某个家族。
- 同时出现两个家族但未明确选择时请求澄清，不能静默选第一个。
- 未提供映射的数据库 ID 不猜测；需要明确的别名/结构化 family 字段。

活动模型缓存以模型组身份及两个权重摘要为键；切换只影响该家族，缺失或损坏时不回退
旧全局模型，也不跨家族兜底。保留 legacy 入口仅供明确兼容调用。

## 6. 推理与输出

执行顺序：输入/家族校验 → 已校验模型组 → 分类 → 回归 → 结构化结果。
分类器输出活性概率，默认概率 `>= 0.5` 显示“有活性”，否则“无活性”。
注意：概率决策阈值 0.5 与训练标签 pIC50 阈值 5 是两个不同概念。

回归器总是输出自身计算得到的连续 pIC50；分类概率不能换算为 pIC50，
不能将“无活性”替换成固定的 0、4.99 或其他模拟值，也不把回归值强行裁剪到分类区间。

结构化结果至少包含：

- requested target、family_id、bundle_id、success/status；
- activity_class、activity_probability、label_threshold=5、probability_threshold=0.5；
- predicted_pIC50、回归单位，以及 classification/regression 的一致性状态；
- 两个 model_id、权重摘要、来源/数据摘要、warnings、阶段错误。

独立模型可能出现“分类无活性、回归 pIC50 >= 5”等不一致。保留原始两项输出和
`classification_regression_consistent=false`，必要时仅提示两项预测不一致，
不得为了让结果好看而覆盖分类或修改数值。

分类阶段失败则不伪造类别，也不继续声称已完成两阶段流程；回归阶段失败时可以保留
已完成的分类，但标记 partial、回归值为 null。完整成功必须两个阶段都成功。
无效 SMILES 不得产生属性、数值或可视化卡片。

前端默认显示“活性分类”“活性概率”“预测 pIC50”，不重复显示家族/物种范围标识；
模型卡、可追溯记录及必要的失败信息仍完整保留。

## 7. 训练与验收顺序

1. 先写家族别名、阈值边界、共享拆分、成组完整性、阶段失败和数值隔离的回归测试。
2. 复用现有单模型训练器，补齐两模型组生命周期与 predictor/Agent/API 接入。
3. 真实数据仅做预检、分类比例/冲突统计和固定拆分检查，报告不含原始记录。
4. 使用训练集和验证集完成小规模工程烟雾检查；此步骤不能提前消费正式 test。
5. 正式训练两家族、两任务共四个模型。validation 选模/早停，冻结方案后每个模型
   只执行一次独立 test 评估；不因 test 指标差反复选超参数。
6. 分类报告 ROC-AUC、PR-AUC、balanced accuracy、混淆矩阵，回归报告 RMSE、MAE、R²。
   与训练集简单基线比较，报告每阶段和组合的一致性/失败率；不预设“效果必然好”。
7. 注册不等于激活：真实模型组通过完整产物检查后再切换；部署/重启不与训练隐式绑定。

训练尚无经真实数据验证的性能阈值，不将 `endpoint_ready` 等工程状态表述为科研性能认证。
真实运行结果不足以支持实际使用时仍如实报告，不包装成成功模型。
