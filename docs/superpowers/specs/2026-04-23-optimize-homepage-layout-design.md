# 2026-04-23 优化主页布局设计方案

## 1. 目标
解决主页布局重心过高、聊天输入框下方空白区域视觉不平衡的问题。通过整体下移重心和优化垂直间距，提升页面的高级感和呼吸感。

## 2. 架构与布局调整
我们将对主内容区域（右侧容器）的布局逻辑进行重构。

### 2.1 主容器调整 (`.index_con .right`)
- **现状**：使用 `justify-content: center` 进行垂直居中，导致内容受顶部 Logo 和标题高度影响，整体偏上。
- **调整**：
    - 改为 `justify-content: flex-start`。
    - 添加 `padding-top: 18vh`。
    - **效果**：将欢迎语、功能图标和聊天输入框整体向下推移至页面的黄金分割线位置（中下部）。

### 2.2 交互组件间距调整
- **聊天输入框下方的控制栏 (`.index_con .right .tool`)**：
    - **调整**：将 `margin-top` 从 `2vh` 增加至 `5vh`。
    - **目的**：拉开输入框与复选框/高级选项之间的距离，使下方的“一行空白”转化为有意的留白空间。

### 2.3 侧边栏对齐调整 (`.index_con .left .data`)
- **调整**：适当增加“数据管理”部分的顶部间距（`margin-top`），使其高度与右侧新的重心保持相对协调。

## 3. 影响范围
- `src/web/templates/index.html`：主要修改内部 `<style>` 标签内的样式。
- `src/web/static/css/style.css`：同步修改外部样式表以保持一致性。
