# 活性预测子功能前端页面优化设计规格说明书 (Spec)

## 1. 项目概述
本项目旨在优化基于 RG-MPNN 模型的分子活性预测子页面。通过提升视觉美化度、增强交互反馈、引入动态可视化图表以及规范专业术语，打造一个具有“未来感”且符合科研标准的分子活性评估工作台。

## 2. 视觉设计风格 (Visual Style)
*   **色调规范**：采用与主页一致的深蓝/靛蓝调。
    *   主色：`#4f46e5` (Indigo)
    *   辅助色：`#1e2738` (Dark Blue Gray)
    *   背景色：`#f8fafc` (Light Gray/White) 或 带有微妙模糊效果的深色毛玻璃背景。
*   **布局重构**：保持当前的三标签页结构，但优化内部边距与组件阴影，对齐首页的圆角风格 (16px+)。
*   **图标系统**：使用统一风格的 SVG 图标，增强视觉的一致性。

## 3. 核心功能与交互 (Features & Interaction)
### 3.1 动态可视化组件 (ECharts 驱动)
*   **活性强度仪表盘 (Activity Gauge)**：
    *   针对单分子预测，通过半圆盘展示活性分值。
    *   分值加载具有弹性过渡动画。
    *   颜色映射：[0.0-0.3] 红色, [0.3-0.7] 橙色, [0.7-1.0] 绿色。
*   **群体活性分布图 (Distribution Histogram)**：
    *   针对批量预测，展示数据集中分子的活性频数分布。
    *   支持点击柱状图过滤下方的结果列表。

### 3.2 动效增强系统 (Animation System)
*   **交错入场 (Staggered Entry)**：表格行、卡片等元素在渲染时依次从底部轻微滑入，延迟 50-100ms。
*   **数字滚动 (Number Counter)**：预测分值、R² 等核心指标从 0 开始滚动至最终数值。
*   **平滑标签切换**：标签页切换时采用淡入淡出及位移过渡，避免元素突变。
*   **加载反馈**：优化 `Predicting` 状态，引入高科技感的分子链增长动画或动态进度条。

## 4. 技术实现方案
*   **图表库**：引入 `https://cdn.jsdelivr.net/npm/echarts/dist/echarts.min.js`。
*   **动画库**：主要使用原生 CSS3 `transition` 与 `animation`，必要时引入简单的 JS 函数处理交错。
*   **数据结构**：兼容现有的 API 返回结构（确保 `activity_score`, `confidence`, `class` 等字段解析正确）。

## 5. 验收标准
1. 页面整体色调与首页 (`index.html`) 及对接页高度统一。
2. 预测完成后，仪表盘动画平滑显示结果。
3. 批量预测结果不仅有表格，还有分布直方图。
4. 动效流畅，无卡顿。
