# 首页目标分析实施与验收

1. 用 WebSocket 测试覆盖目标创建、运行中更新、过期修订、其他连接和已结束任务。沿用现有会话所有者、模型租约和超时监督。
2. 将模型的工具提案绑定到本次用户提供的完整输入。使用注册表中的工具适配器验证原始结果，按实际参数和版本标识可复用项。
3. 每次只派发当前计划中缺少的一项，再将观察结果交给模型。测试迟到的旧提案、在途工具收尾、结果复用和变更参数后的重新计算。
4. 首页在运行中接收新目标，按修订号展示进度。保留普通聊天和对接确认的已有交互。
5. 用真实浏览器和首页模型在两次工具调用之间修改目标，核对初始步骤、复用项、新步骤及最终结果。结束后关闭临时服务。
