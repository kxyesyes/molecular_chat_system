# ADMET-AI 1.4.0 接入实施计划

> 状态：候选实现已完成，等待合并。范围限定为 ADMET-AI 接入、现有 `admet_predictor` 契约适配、Agent 数据流验证和相关文档；不重写 Agent，不切换生产入口，不提交模型权重或运行产物。

## 目标与约束

- 在 Python 3.10 独立环境中验证并固定 `admet-ai==1.4.0`；生产入口必须通过 worker 运行。
- 用 ADMET-AI 随包的真实模型权重执行本地推理；模型不可用、输入无效或超时必须显式失败/部分失败。
- 保留 `admet_predictor` 工具名、ToolResult、Validator、批量输入和现有下游排序接口。
- 每条结果保留 `molecule_id`、原始/规范 SMILES、终点值、单位、模型版本、权重标识、warnings 和 provenance。
- 规则/RDKit 计算与 ADMET-AI 预测分离，不以规则或 fallback 填充模型结果。

## 阶段

1. **基线与接口核对**：读取现有调用链、契约、Validator、候选排序和测试；在独立探针环境核对 ADMET-AI 1.4.0 API、权重路径和依赖。
2. **TDD RED**：新增单元契约测试，覆盖模型边界、批量身份、无效 SMILES、模型缺失、超时、provenance、有限数值和候选数据流；先运行确认失败。
3. **最小实现**：增加 ADMET-AI 适配层和缓存/批量/超时控制；将 `ADMETPredictor` 只把真实 ADMET-AI 结果作为模型结果，保留显式规则/描述符但不冒充 ADMET 预测。
4. **契约与下游接线**：扩展分析契约和领域 Validator，保留既有 UI/ranker 所需兼容字段；确保生成候选按 ID/SMILES 进入 ADMET 和排序，失败项不被静默丢弃。
5. **真实验收**：在 Python 3.10 独立环境安装/验证 1.4.0，执行单分子、批量、重复、无效输入和超时测试，记录 latency、模型/权重 provenance、失败原因；不宣称准确率已验证。
6. **文档与交付**：更新部署/配置说明和验收报告，运行聚焦回归、compileall、既有 Agent 测试；精确提交本分支并创建 draft PR，绝不合并 `main`。

## 验收门槛

- 生产工具没有 ADMET-AI 真实后端时返回失败/部分失败，不返回 `rdkit_rules` 或 demo 模型行作为 ADMET 预测。
- 无效 SMILES 逐项失败，合法分子结果不会发生行错配；批量输出顺序与输入一致。
- 每个成功模型结果包含非空模型版本、权重标识、单位/终点元数据、`demo_mode=false`、`fallback_used=false`。
- 超时不产生科学数值；候选生成→ADMET→排序测试能证明下游消费的是同一批规范 SMILES。
- 真实权重测试失败时报告具体依赖/设备/权重原因，不伪造通过。
