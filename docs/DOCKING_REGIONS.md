# 空腔定位与 Vina 姿势分析

对接页载入 PDB/PDBQT 受体后自动识别候选空腔，默认选中体积最大的候选，并在蛋白视图显示搜索盒。可切换候选或编辑中心和三轴边长，自定义搜索区域。识别过程中手工编辑的区域会保留。如果没有候选，手动输入盒中心后仍可提交。

几何搜索使用第一模型的 ATOM 重原子，取空白或 A 替代构象。在 1.5 Å 网格上将距蛋白原子 ≤2.4 Å 的点标为占据，保留距最近原子 ≥3 Å 且六个方向中至少五个在 9 Å 内遇到占据点的格点。按面相连的格点形成候选，以格点数估计体积并排序。页面最多列出五个体积 ≥55 Å³ 且搜索盒各轴不超过 50 Å 的候选。候选体积描述几何空隙，不能代替可成药性评价。该实现采用本地网格法，方法与 CB-Dock3 的 CurPocket 有别。

载入配体后点击「开始分子对接分析」。每个任务搜索当前选定的一个区域。完成后可从 Vina 结果表逐个查看姿势，在三维视图叠加前 N 个构象，或下载 PDBQT。Vina 评分单位为 kcal/mol。

「下载全部构象 PDBQT」保留整次 Vina 输出。点击某行的「查看」后，「下载所选构象 SDF」导出该姿势的配体坐标。报告支持 Markdown、HTML 和 ZIP，记录所选 Pose、Vina 评分、相互作用分析、当前三维截图和完整评分表。ZIP 另含原始多构象 PDBQT 和以实际 Pose 编号命名的 PDB。在「对接历史」中恢复已完成的持久化任务，页面会校验并载入该任务保存的受体。刷新后仍可切换构象和导出带图报告。原受体缺失或校验失败时，保留评分表和概览报告。

接口沿用浏览器会话。`POST /api/docking/cavities` 接收 `protein_file`，返回识别方法、网格间距和候选的 `center`、`size`（Å）、`volume`（Å³）。选择候选或手动确认坐标后，向 `POST /api/docking/tasks` 提交受体、配体、盒中心、边长及 `manual_center=true`。随后通过任务状态、结果摘要和逐姿势 SDF 接口读取实际结果。
