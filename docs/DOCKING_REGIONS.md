# 空腔定位与双引擎姿势比较

对接页载入 PDB/PDBQT 受体后，点击「识别候选空腔」，选择一个候选即可把中心和三轴边长写入 Vina 表单，并在蛋白视图显示搜索盒。可以继续编辑六个数值，自定义区域。每次提交使用当前选中的一个区域。

几何搜索使用第一模型的 ATOM 重原子，取空白或 A 替代构象。在 1.5 Å 网格上将距蛋白原子 ≤2.4 Å 的点标为占据，保留距最近原子 ≥3 Å 且六个方向中至少五个在 9 Å 内遇到占据点的格点。按面相连的格点形成候选，以格点数估计体积并排序。页面最多列出五个体积 ≥55 Å³ 且搜索盒各轴不超过 50 Å 的候选。候选体积描述几何空隙，不能代替可成药性评价。该实现采用本地网格法，方法与 CB-Dock3 的 CurPocket 有别。

单分子任务完成后，在姿势表下展开「FitDock 与 Vina 姿势比较」。

- 已有 FitDock 结果时，导入同一受体坐标系下、与查询配体化学结构一致的单个三维 MOL2 或 SDF。导入文件的生成工具及坐标系由提供者确认。
- 在取得适用的 FitDock 发行包后，将可执行文件配置到服务进程的 `MEDCHAT_FITDOCK_BIN` 或 PATH。模板运行需要 Open Babel 命令行工具、PDB 受体以及已对齐到该受体的模板配体 MOL2。程序使用原任务受体的第一模型，保留蛋白原子及识别的金属离子。以 Vina 最佳姿势提供查询配体，以模板引导 FitDock 采样。此模式需要用户提供模板。可从[作者页面](http://cao.labshare.cn/fitdock/php/index.php)获取程序和使用条件。
- 姿势表显示原始 Vina 评分以及相对于 FitDock 姿势的重原子 RMSD。RDKit 在受体坐标系内考虑配体对称性，不重新叠合坐标。两列按升序分别排名，并列取平均名次；两列名次的算术平均值为共识排序依据。在受体已载入的当前任务中点击姿势即可三维叠加。

HTTP 接口沿用浏览器会话。空腔接口 `POST /api/docking/cavities` 接收 `protein_file` 并返回方法、网格间距和候选的 `center`、`size`（Å）、`volume`（Å³）。`GET /api/docking/fitdock/status` 返回本机程序是否可发现。`POST /api/docking/tasks/{task_id}/consensus` 要求当前会话拥有已成功的持久化对接任务，接收 `structure` 文件与 `mode=template|import`。响应提供姿势明细、参考 SDF、输入和参考结构摘要及排序版本。本次比较按需计算，刷新后可重新导入。

工作流参考 [CB-Dock3 论文](https://doi.org/10.1093/nar/gkag417) 与 [FitDock 论文](https://doi.org/10.1093/bib/bbac087)。
