Run a fixed case

These four presets are isolated acceptance obligations, not general chat workflows. The server owns prompts, tools and permissions. Start sends only the selected case ID.

The clarification preset's expected reply is SMILES: CCN. Other molecules do not satisfy this fixed acceptance case. Resume is available only after a waiting_for_input complete message, not merely agent_result. The continuation stays in this page's memory.

Connection & session

Reconnect uses the existing server-owned HttpOnly cookie; it never replays work. Reset closes this connection, rotates the session and clears local results.

A closed connection leaves execution uncertain. It does not prove a server tool has physically stopped.
